How to Host on GitHub Pages & Add to Manager.io

  1. Create a GitHub repository (e.g., manager-personal-finance) and upload this file as index.html.
  2. Enable Settings → Pages → Branch: main to get your HTTPS URL (e.g., https://username.github.io/manager-personal-finance/).
  3. In Manager.io, open your Business → Settings → Extensions → New Extension.
  4. Choose an available placement and paste your GitHub Pages URL. The extension only reads data; it does not create or edit accounting entries.

Use the Manager.io Extension connection

This dashboard uses Manager.io's documented iframe message bridge. It does not need an API token, password, or separate server URL when opened as an Extension.

  1. Host this file as index.html on GitHub Pages (HTTPS).
  2. In Manager.io, open the business and go to Settings → Extensions.
  3. Add a new extension and enter your GitHub Pages URL.
  4. Open the extension inside the business, then click the refresh icon to retry the live connection.
